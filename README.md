# runeska-config

Публичная точка конфигурации OTA-обновлений RuNeska.

`config.json.enc` — адрес панели обновлений, **зашифрованный** (XChaCha20-Poly1305)
и **подписанный** (Ed25519). Клиент RuNeska тянет этот файл при старте, проверяет
подпись вшитым публичным ключом, расшифровывает и получает адрес.

Шифртекст здесь не раскрывает адрес, а подпись не даёт его подменить. Чтобы сменить
адрес панели — пересоберите и запушьте новый `config.json.enc` (инструмент у владельца).
